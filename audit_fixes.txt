Audit summary — Gamebook Studio

I went through the engine systematically with a headless test harness (since arcade can't open a window here) and fixed every crash and layout defect I could reproduce. All 24 automated checks now pass with zero crashes and zero button overlaps.

Crashes fixed

    Studio crashed on every node click. The inspector built TextInput(..., placeholder=...) and Button(..., subtitle=...) with parameters the widgets didn't accept, and read .y on a field that only had .cy. Rewrote TextInput to be bottom-anchored with .y / .top / .cy, and added the missing params.
    Studio "Apply" / choice "Save" would crash. Code read input.text but the widget only exposed .value — a latent AttributeError even in the original. Added a .text property.
    "Duplicate scene" crashed on a non-existent Scene.ambient_color field (and wrong types for ambient/on_enter). Corrected to the real fields.
    Mid-play crash on integer effect values like stat_endurance: -1; the stat-flash routine assumed every value was a "stat:DC" string. Rewrote it to handle ints and both key forms.

Data fixes (silent corruption)

    Effect suffixes like add_item2, add_item3 were being dropped — 31 effects across the 3 sample books silently vanished (e.g. a scene that should grant 3 items granted 1). Now all three items are granted. Both the README's direct forms (stat_might, min_might:8) and the colon forms the books actually use ({"stat":"valor:-2"}, {"min_stat":"might:12"}) are honored, plus remove_codeword / add_note.

Interface / overlap fixes

    The first inventory slot overlapped the "INVENTORY" header with 6-stat books; rewrote the sidebar to use one top-down cursor (verified clean on all three books).
    Choices were top-anchored and ran off-screen at 7+ options; now bottom-anchored, auto-sized to always fit (verified with 8 choices).
    Repositioned the toolbar progress text so it no longer collides with the HUD icons.

New options / workflow

    In-game Settings overlay (text speed, font size, master volume, dice + autosave toggles) on a new ⚙ icon / O key, persisted to config.json; added a ⌂ quit icon.
    Rich choice editor: edit target, roll, fail-target, conditions, effects, and tags (not just text/target), with round-trip parsing verified.
    "Set as Start" button, apply-on-blur (edits no longer lost when clicking another node), and Studio shortcuts: V validate, Ctrl+D duplicate, Ctrl+N/+ add, -/Delete delete.
